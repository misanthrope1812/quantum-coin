# Quantum Coin — Орёл или Решка

Монетка, которая решает «орёл или решка» по **аппаратному квантовому генератору случайных чисел**
Австралийского национального университета (ANU QRNG). Если сети нет — по криптографическому ГСЧ браузера.
Работает как приложение на iPhone и Android (PWA): ярлык на экране «Домой», открывается без сети.

## Как это работает

1. При запуске приложение берёт у `qrng.anu.edu.au` сразу 1024 квантовых байта и хранит их в `localStorage`.
   Бесплатный API ANU отвечает не чаще раза в минуту, поэтому байты берутся про запас: одного запроса хватает на 1024 броска.
2. Каждый бросок тратит один байт: чётный — **орёл**, нечётный — **решка** (256 значений делятся поровну, перекоса нет).
3. Если запас кончился, а ANU недоступен или ещё не прошла минута, байт берётся из `crypto.getRandomValues`.
   Под результатом видно, откуда он пришёл: `ANU QRNG` (зелёная точка) или `CSPRNG` (золотая).
4. Результат известен **до** приземления, анимация просто докручивает монету до нужной стороны.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и стили |
| `app.js` | квантовый запас, анимация броска, статистика, регистрация service worker |
| `coin.js` | рисует обе стороны монеты в SVG |
| `sw.js` | офлайн-кэш. **После любых правок увеличьте `VERSION`** (`qc-v1` → `qc-v2`), иначе телефоны покажут старую версию |
| `manifest.webmanifest`, `icons/` | данные для установки как приложения |
| `sounds/` | звуки броска: `flick.mp3` — щелчок при подбросе, `land.mp3` — монета падает на стол |

Звуки взяты с [Pixabay](https://pixabay.com/service/license-summary/) (бесплатная лицензия, указание автора не требуется),
подрезаны и выровнены по громкости:
[coin flip](https://pixabay.com/sound-effects/film-special-effects-coin-flip-37787/) (freesound_community) и
[Wood Surface Single Coin Payout 4](https://pixabay.com/sound-effects/film-special-effects-wood-surface-single-coin-payout-4-215284/) (floraphonic).
На iPhone звук, как и у других приложений, выключается переключателем «Без звука».

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `quantum-coin`) и загрузите в корень все файлы из этой папки
   (через **Add file → Upload files** или `git push`).
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/quantum-coin/`.

## Установка на iPhone

Откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
Приложение откроется на весь экран, без адресной строки, и будет работать без сети.

## Локальный запуск

Service worker не работает с `file://`, нужен локальный сервер:

```bash
python -m http.server 8765
```

и откройте `http://localhost:8765`.
